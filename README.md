Entry for the make.fun bounty [One Emoji, One Dream Vacation](https://make.fun/bounty/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35): a single emoji that makes a stranger want to book a flight.

> 🛖

One hut, one island, one dream: a thatched hut is the whole postcard — somewhere far away, somewhere you actually sleep, not just a beach you look at.

`main.ts` reads `entry.txt` at runtime and copies it verbatim to `$MAKEFUN_OUTPUT_DIR/entry.txt`, after validating that it is exactly one emoji.
